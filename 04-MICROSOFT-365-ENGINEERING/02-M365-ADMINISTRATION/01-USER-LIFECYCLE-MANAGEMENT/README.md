# Project 01 – Microsoft 365 User Lifecycle Management

[![Windows](https://custom-icon-badges.demolab.com/badge/Windows-0078D6?logo=windows11&logoColor=white)](#)

## Overview

This project demonstrates the complete onboarding and offboarding lifecycle of a Microsoft 365 user account using Microsoft Entra ID, Microsoft 365 Admin Center, and Exchange Online.

# Key Takeaways

This project demonstrates hands-on experience with common Microsoft 365 administrative tasks performed by:

- IT Support Specialists
- Help Desk Technicians
- Microsoft 365 Administrators
- Systems Administrators
- Cloud Support Engineers

The lab simulates a real-world employee onboarding and offboarding process while applying identity management and security best practices.
