# Active Directory / Microsoft 365 User & Role Management Project

## Overview
This project demonstrates user administration within Microsoft 365 / Microsoft Entra ID, including user creation, group management, role assignments, license management, and password reset validation.

## Project Tasks
- Create users
- Create security groups
- Add users to groups
- Assign administrative roles
- Assign licenses
- Verify role permissions
- Perform password reset operations
